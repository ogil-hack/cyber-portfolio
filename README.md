# Cyber Portfolio

Welcome to my cybersecurity repository. Here you'll find writeups from CTFs 
I've solved, mainly on HackTheBox, scripts in various programming languages, 
and notes from my ongoing cybersecurity studies.

## What's inside

- **CTF Writeups** — step-by-step solutions and methodology for retired 
  HackTheBox labs and other machines
- **Scripts** — tools and automation I've built, mainly in Python, while 
  learning offensive security
- **Notes** — study material on networking, Linux tools, and security 
  fundamentals

## Contributing
This is a learning project — if you spot mistakes or vulnerabilities in the code, feel free to open an issue or PR!
